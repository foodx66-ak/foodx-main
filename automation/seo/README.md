# SEO自動サイクル（foodx.co.jp）

GitHub Actions で毎月1日・15日に実行します。

1. 効果測定：マージ後35日を過ぎた施策を判定
2. 候補抽出：基準を満たす /lab/ 記事を機械的に選ぶ
3. 提案：Claude API
4. 機械検証：許可リスト、文字数、数値の照合、禁止表現
5. 変更：commit → PR作成
6. 記録：施策ログ（スプレッドシート）に記録
7. 通知：Slack

**マージだけは人が行います。** 不要な PR はクローズすれば「却下」として記録されます。

- 挙動の調整は `config.mjs` だけで行えます
- テストは `npm test` で実行します（外部サービスには接続しません）
- このリポジトリは Public です。秘密情報は GitHub Secrets に置いてください。分析の中身はログに出さない設計です
- `automation/` と `.github/` は `.vercelignore` でサイトの配信から除外しています
