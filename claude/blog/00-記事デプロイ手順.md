# 記事・ページ デプロイ手順（共通メモ）

最終更新: 2026-10-09

## 2-1. 共通（フレームワーク・デプロイ・プレビュー）

| 項目 | 内容 |
|---|---|
| フレームワーク | 静的HTML（Design Component / `*.dc.html`）＋ `support.js`。Next.js 等ではない |
| デプロイ先 | Vercel（`vercel.json` の rewrite / redirect） |
| ビルド | `package.json` に build スクリプトなし。静的配信 |
| プレビュー | ローカルは HTML を直接開く／本番相当は Vercel Preview。`npm` の preview コマンドは未定義 |
| ページと URL の対応 | `*.dc.html` を `vercel.json` の `rewrites` できれいなパスにマッピング（例: `/google-profile` → `/GoogleProfile.dc.html`）。旧 `.dc.html` URL は `redirects` で正規パスへ 301 |

主な rewrite 例:

- `/` → `/AIkata.dc.html`
- `/google-profile` → `/GoogleProfile.dc.html`
- `/contact` → `/Contact.dc.html`
- `/about` → `/About.dc.html`
- `/reo` → `/REO.dc.html`
- `/grease-ozonizer` → `/GreaseOzonizer.dc.html`

`lab/` 配下はディレクトリごとの `index.html` をそのまま配信。

## お問い合わせ・リード管理

- お問い合わせフォーム（`Contact.dc.html`）およびページ内リードは `POST /api/contact`（Vercel Serverless: `api/contact.js`）へ送信
- 送信経路: `/api/contact` → Resend → `CONTACT_TO`（デフォルト `contact@foodx.co.jp`）
- 問い合わせの種別は JSON ボディの `topic` で区別する（件名: `【お問い合わせ】{topic}｜{name}様`）
- 既知の topic 例: `AIkata（経営OS）` / `Googleプロフィール代行` / `AIO診断` / `30秒診断` など
- 必須項目（API）: `name` / `email` / `message`。ハニーポット `company_hp` に値があると静かに破棄
- 環境変数: `RESEND_API_KEY`（必須）、`CONTACT_TO`、`CONTACT_FROM`
