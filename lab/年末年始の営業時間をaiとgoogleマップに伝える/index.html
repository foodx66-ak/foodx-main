年末年始の営業時間を、AIとGoogleマップに正しく伝える手順

公開日：2026年12月2日　｜　FooDX合同会社

年末年始は、AIやGoogleマップで「今日開いている店」を探す人が増える時期です。ところが、店の情報が通常の営業時間のままだと、AIは「営業中」と答え、客は閉まった店の前で引き返すことになります。逆に、営業しているのに「休業」と出れば、来るはずの客を逃します。

この記事では、年末年始の営業時間を、Googleマップ、AI、公式サイト、グルメサイトに正しく伝える手順を、締め切りの目安つきでまとめました。最後に、そのまま使える点検表を付けています。

この記事の要点

  1. まずGoogleビジネスプロフィールの「特別営業時間」を入れる。AIもGoogleマップも、ここを手がかりにします。
  2. 公式サイト、グルメサイト、SNS、予約台帳も同じ日時にそろえる。1か所でも食い違うと、確かめた客が離れます。
  3. 入れたあとに、AIとGoogleマップで実際にどう出るかを確かめる。年明けには通常の表示に戻っているかも確かめます。

なぜ年末年始の営業時間が大事なのか

客は、AIで候補を絞ったあと、Googleマップや口コミ、公式サイトで確かめてから店に向かいます。この「確かめる」段階で情報が古かったり食い違っていたりすると、その店は候補から外れます。情報の不備で店を候補から外した経験がある人は、AIを店探しに使う人で8割以上、使わない人でも7割以上いました（訪日ラボ、2026年9月）。Googleマップで店を調べたことがある人の36.0%は、情報が足りなければ別の店を選ぶと答えています（FINEXT、2026年2月、n=317）。

年末年始は、店ごとに営業日と時間がばらばらになる時期です。客の側も「開いているか」を確かめたいので、ここで正しく出ている店は、それだけで選ばれやすくなります。

手順1：営業する日と時間を、先に1枚に決める

媒体ごとに入力していくと、どこかで日付や時間がずれます。まず、12月28日ごろから1月5日ごろまでの予定を1枚の表に決めてから、それを各媒体に写していきます。

日付営業時間ラストオーダーメモ
12月30日（例）営業17:00〜23:0022:30通常より1時間早く閉める
12月31日〜1月3日（例）休業――
1月4日（例）営業17:00〜24:0023:30通常どおり

表の日付と時間は記入例です。

ラストオーダーや、通常と同じ日も書いておくと、あとで入力するときに迷いません。

手順2：Googleビジネスプロフィールに「特別営業時間」を入れる

Googleマップの表示も、GoogleのAIによる概要やAIモードの回答も、Googleビジネスプロフィールの情報が土台になります。年末年始の予定は、通常の営業時間を書き換えるのではなく、「特別営業時間」として日付ごとに入れます。

  1. Googleビジネスプロフィールで「プロフィールを編集」から「営業時間」を開きます。
  2. 「特別営業時間」の編集アイコンを選び、日付を追加します。Googleが祝休日を提示している場合は「確認」から入れられます。
  3. 営業する日は「休業」のチェックを外して時間を入れ、休む日はチェックを入れたままにします。
  4. 保存します。特別営業時間は、指定した日にだけ適用されます。

Googleのヘルプには、つまずきやすい点も書かれています。飲食店に関わるものを抜き出しました。

  • 深夜0時をまたぐ営業：1つの特別営業時間は24時間以内です。0時をまたぐ場合は、日をまたぐ前と後の2つの時間帯に分けて入れます。
  • 通常どおり営業する祝休日：元日などの祝日は、通常と同じ時間でも特別営業時間を入れておくことがすすめられています。
  • 7日以上の連続休業：7日以上続けて休む場合や、再開日が決まっていない場合は、特別営業時間ではなく「臨時休業」にします。
  • 営業時間の設定そのもの：特別営業時間を表示するには、通常の営業時間が「決まった営業時間で営業している」になっている必要があります。

あわせて、「最新情報」の投稿で年末年始の営業予定を知らせておくと、店のプロフィールを見た人に伝わりやすくなります。

手順3：公式サイトに、文字で書く

公式サイトには、年末年始の予定を画像ではなく文字で書きます。画像だけだと、AIや検索エンジンが読み取れないことがあるためです。トップページか、営業時間を書いているページの上のほうに置くと、確かめに来た人もすぐ見つけられます。

サイトに構造化データ（schema.org）を入れている場合は、特別営業時間も書き足せます。例を載せます。

"specialOpeningHoursSpecification": [
  {
    "@type": "OpeningHoursSpecification",
    "opens": "00:00",
    "closes": "00:00",
    "validFrom": "2026-12-31",
    "validThrough": "2027-01-03"
  },
  {
    "@type": "OpeningHoursSpecification",
    "opens": "17:00",
    "closes": "23:00",
    "validFrom": "2026-12-30",
    "validThrough": "2026-12-30"
  }
]

休業の日は、Googleの構造化データのガイドにならって opens と closes を両方「00:00」にしています。店の Restaurant の構造化データの中に入れます。日付と時間は記入例です。

構造化データを入れていない場合は、文字で書くだけでも十分です。構造化データの入れ方は、このシリーズの別の記事で詳しく取り上げます。

手順4：グルメサイト、SNS、予約台帳をそろえる

Googleビジネスプロフィールと公式サイトを直したら、同じ日時でほかの媒体もそろえます。

媒体やること
グルメサイト（食べログ、ぐるなび、ホットペッパーグルメなど）店舗の管理画面で営業時間の備考やお知らせに年末年始の予定を書く。掲載中のサイトはすべて
Instagram、XなどのSNS年末年始の予定を投稿し、プロフィールの上に固定する
LINE公式アカウント常連に配信する。年明けの営業開始日も一緒に伝える
予約台帳・ネット予約休業日の受付を止める。営業時間を短くする日は、受付できる時間を合わせる
店頭・電話入口の貼り紙と、留守番電話の案内を合わせる

いちばん起きやすいのは、Googleでは休業なのにネット予約が取れてしまう、という食い違いです。予約台帳の設定は忘れずに確かめてください。

手順5：AIとGoogleマップで、どう出るか確かめる

入れただけでは終わりません。実際に客と同じように聞いて、正しく出るかを確かめます。

  1. Googleマップで店名を検索し、年末年始の日付の営業時間が出ているかを見ます。
  2. ChatGPT、Gemini、GoogleのAIモードに「（店名）は12月31日に営業していますか」と聞きます。
  3. 答えが違っていたら、どこの情報を見ているかを聞き返します。古い情報の出どころがわかれば、そこを直します。

AIの回答は、情報を直してもすぐには変わらないことがあります。早めに入れて、12月中旬と年末の2回確かめるのがおすすめです。自店がAIにどう出ているかを確かめる質問のひな形は、次回の記事で配布します。

手順6：年明けに、表示を戻す

特別営業時間は指定した日にだけ適用されるので、Googleマップは自動で通常の時間に戻ります。一方で、公式サイトのお知らせ、SNSの固定投稿、グルメサイトの備考は、自分で外すまで残ります。年明けの営業初日に、まとめて片づけましょう。古い「休業のお知らせ」が残っていると、それ自体が食い違いになります。

点検表：年末年始の営業時間

このまま印刷して、終わったものに印を付けて使えます。

済やること目安
□営業する日と時間、ラストオーダーを1枚の表に決めた12月上旬
□Googleビジネスプロフィールに特別営業時間を入れた（0時をまたぐ日は2つに分けた）12月10日ごろまで
□元日など、通常どおり営業する祝日にも特別営業時間を入れた同上
□Googleビジネスプロフィールの「最新情報」で予定を投稿した同上
□公式サイトに文字で書いた（構造化データがあれば特別営業時間も）同上
□掲載中のグルメサイトすべてに書いた12月中旬まで
□SNSに投稿して固定し、LINEで常連に配信した12月中旬まで

□年明けに、サイト・SNS・グルメサイトのお知らせを外した営業初日

まとめ：年末年始は「確かめても崩れない店」の練習になる

年末年始の営業時間をそろえる作業は、店の情報をすべての媒体で一致させる、という集客の基本そのものです。一度やってみると、自店の情報がどこに何か所載っているかがわかります。年明けからは、メニューや価格、写真でも同じことを続けていきましょう。

FooDXは、AIに見つけられ、確かめても崩れない店の情報づくりを、店に合わせて伴走しています。AIで飲食店探しがどう変わったかは、飲食店探しはAIでどう変わったかで整理しています。
